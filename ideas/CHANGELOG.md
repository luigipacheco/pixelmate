# PixelMate 1.0.0

First public release of PixelMate, with Bitsy the walking pixel pet.

- Steps become sparks (20 steps = 1 spark); Bitsy needs half your daily goal
  in steps to stay healthy.
- Six arcade games: Spark Slots, Spark Stack, Spark Grid (levels 1-5),
  Bit Flip, Bitsy Says and HI-LO.
- Store with eye colors, pixel styles and animations.
- Photo booth for the camera module: three lenses, COLOR FILM, twelve looks,
  GIFs, a web gallery and a Wi-Fi webcam.
- TOOLS page with sensor apps, plus Interaction module support.
- Clock mode on USB power, pocket mode on battery, TAP STEPS accessibility
  mode, 8-bit sounds, Wi-Fi setup hotspot and a stats web page.
